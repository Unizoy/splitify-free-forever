## Summary

Adding an expense got Splitwise's shortcuts and Splitwise Pro's entry tools, free: a two-person expense is one tap
("You are owed the full amount"), a bill can be split by items with tax / service / tip / discount shared in
proportion, a receipt photo is read on the phone (offline) to fill the amount, date, description and items, a
deleted expense opened from Activity can be restored on its own page, the cursor goes where typing continues after
"With you and", the expense page shows the category's last three months, and a receipt picture or a UPI app's
"Paid ₹250 to …" text can be shared to Splitify.

## APK size (S-370)

`flutter build apk --release --target-platform android-arm64` (.qa build, same command before and after):
23,074,875 → 36,986,670 bytes (22.0 → 35.3 MB, +13.9 MB). That single APK also carries the plugin AARs'
armeabi-v7a and x86_64 libraries (Flutter's `--target-platform` filters only its own). What an arm64 phone gets,
`--split-per-abi` arm64-v8a: 24,672,094 bytes (23.5 MB) after; before ≈ 18.7 MB (the baseline APK minus its v7a
and x86_64 entries) → about +5.9 MB (OCR library 4.41 MB compressed, models 1.27 MB, dex +0.16 MB). Owner option
(not done, `build.gradle.kts` is not WP-A's): `ndk.abiFilters` for the universal phone APK would drop the x86_64
copies (OCR 4.5 MB + barcode 2.4 MB).
