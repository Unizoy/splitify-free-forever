# Security Policy

## Supported versions

The project is in early development. Only the latest code on the `main` branch receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue, discussion or pull request for security problems.

Report it privately through GitHub:

1. Go to the [Security tab](https://github.com/Unizoy/splitify-free-forever/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, how to reproduce it, and its possible impact.

We aim to acknowledge reports within 7 days and will keep you updated while we work on a fix.
Please give us reasonable time to release a fix before disclosing the issue publicly.
